# agent-skills

一组给 AI Agent 用的技能包（Skill）。每个 Skill 是一个带 YAML frontmatter 的 Markdown 文件，放进 agent 的 skills 目录后，用日常说法就能触发，不需要记命令。

仓库按合集组织，目前收录一个：

| Skill | 用途 |
| --- | --- |
| [resume-competitiveness](skills/resume-competitiveness/SKILL.md) | 围绕具体求职目标，诊断简历为什么拿不到面试 |

## resume-competitiveness：简历竞争力诊断

投简历最难受的阶段，是不知道问题在哪。岗位投了不少，回复寥寥，于是开始改措辞、换模板、加粗关键词，改完还是没动静。这个 Skill 把诊断拆成能验证的几步，先判断问题类型，再决定要不要改简历。

### 它会做什么

- 先确认目标岗位、职级、城市和薪资，再评价简历。没有目标的“竞争力”没有意义。
- 从三个维度给判断：基础竞争力（是否达到目标职级）、差异化竞争力（和同层级候选人比有什么）、能力证明（核心项目能否支撑主张）。
- 把问题归到四类：表达问题、证据问题、能力问题、定位问题。不同类型对应不同动作，改简历只对表达问题有效。
- 审查 2–4 个核心项目，指出已证明的能力、证据缺口，以及值得追问的细节。
- 给出 P0/P1/P2 行动清单，说明每项需要什么真实材料。
- 如果有投递数据，帮你设计下一轮验证：固定变量、分阶段记录投递→回复→面试。

### 它不会做什么

- 不替你编经历、数字或项目。
- 不把“简历里没写”当成“你不具备”。
- 不做排版和单纯润色，也不从零代写简历。
- 不给“包装一下就能拿 offer”这类承诺。

### 怎么触发

装好后直接用自然语言问，例如：

- 帮我看看这份简历有没有竞争力
- 投了 80 份没面试，问题出在哪
- 这段项目经历算有含金量吗
- 我是不是求职定位偏了
- 复盘一下上个月的投递数据

### 需要准备的材料

必需：简历原文、目标岗位、目标职级。

有帮助：目标城市和薪资预期、具体 JD、投递渠道与数量、回复和面试数据。

材料不全也能做条件式诊断，但结论会绑定你给出的假设。

## 安装

要求：支持 `SKILL.md` 的 agent 客户端。不需要额外依赖。

```bash
git clone https://github.com/chake111/agent-skills.git
mkdir -p ~/.agents/skills
cp -r agent-skills/skills/resume-competitiveness ~/.agents/skills/
```

ZCode 读取 `~/.agents/skills/`。Claude Code 用 `~/.claude/skills/`，把上面的目标路径换掉即可。其他客户端放进各自的 skills 目录。

装好后新开一个会话，客户端会重新扫描 skills 目录。

## 设计原则

- 目标优先：脱离岗位、职级、城市的竞争力判断没有参考价值。
- 证据优先：每个优势都要能落到项目或结果上，常见技术栈不算差异化。
- 区分事实与推断：材料里没有的，标成信息缺口，不补写。
- 用反馈校准：投递数据用来验证诊断，避免把简历当成唯一变量。

## 隐私

简历包含个人信息。使用前删掉身份证号、住址、紧急联系人等与求职判断无关的内容。这个仓库只有 Markdown 文件，不包含上传或遥测代码。
